# Tognoli Arborismo - Professional Tree Services

Professional website for **Tognoli Arborismo**, a specialized tree pruning and removal service based in Escobar, Buenos Aires.

Built with **Astro**, **Tailwind CSS v4**, and **GSAP**.

## 🚀 Features

- **Blazing Fast Performance:** Static site generation via Astro.
- **Modern Styling:** Powered by Tailwind CSS v4 with a custom color palette.
- **Dynamic Content:** All business data (phone, address, social) is centralized in a single configuration file.
- **SEO Optimized:** Meta tags, Open Graph, Twitter Cards, and JSON-LD LocalBusiness structured data are pre-configured.
- **Responsive Design:** Mobile-first approach with optimized assets.
- **Interactive UI:** Smooth scroll, FAQ accordions, and subtle animations using GSAP and CSS.

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

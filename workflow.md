Standardize the structure and style of the CV by sections:

- PROFESSIONAL SUMMARY
- EXPERIENCE
- SKILLS
- EDUCATION
- LANGUAGES

Five CV focus versions: frontend, backend, fullstack, AI engineer.

For each specific case, the semantics and focus must be optimized:

- frontend: frontend developer with some backend and AI knowledge

- backend: backend developer with some frontend and AI knowledge

- AI engineer: AI solutions engineer with fullstack development experience

- fullstack: neutral developer profile, geared towards fullstack positions

- super neutral profile (Spanish only): neutral profile adaptable to any position, even outside the technology sector

Languages for each tech version: English - Spanish. The translations shouldn't be direct word-for-word; there should be logical changes. For example, in a Spanish CV, it's not necessary to specify native Spanish speaking skills because it's already assumed. In an English CV, it might be appropriate to specify both languages.

Objective: To standardize all of this so there's a quick iteration of the content for all nine CVs.
